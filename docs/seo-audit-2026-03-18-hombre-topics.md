# Auditoría SEO Hombre - 5 artículos nuevos prometedores

Fecha: 2026-03-18

Base de análisis:
- Search Console (`sc-domain:tuasesordemoda.com`, últimos 90 días)
- inventario actual de artículos categoría `hombre`
- clusters ya validados en el sitio

## Resumen ejecutivo

Hoy el sitio muestra dos señales fuertes dentro de hombre:

1. El cluster de **tipos de rostro + cortes** ya tiene tracción real.
   - `cara-diamante-hombre`
   - `tipos-de-rostros-de-hombre`
   - `cortes-y-peinados-de-hombre`

2. El cluster de **outfits masculinos** también tiene demanda, pero está demasiado concentrado en piezas amplias:
   - `outfit-hombre`
   - `como-vestir-para-una-boda-sin-traje`
   - `como-vestir-para-una-boda`

La mejor oportunidad no es abrir temas completamente nuevos, sino **desagregar intenciones claras que ya están cerca de funcionar** y que hoy no tienen una URL específica.

## Artículos recomendados

### 1. Rostro ovalado hombre: características y cortes que favorecen

**Slug sugerido**
- `rostro-ovalado-hombre`

**Keyword principal**
- `rostro ovalado hombre`

**Longtails**
- `cara ovalada hombre`
- `cortes para rostro ovalado hombre`
- `peinados para rostro ovalado hombre`
- `famosos con rostro ovalado hombre`

**Por qué conviene**
- `tipos-de-rostros-de-hombre` ya tracciona con queries de famosos y formas de cara.
- `cara-diamante-hombre` confirma que una URL específica por forma facial sí puede captar demanda.
- `rostro ovalado` ya aparece en Search Console del sitio, pero hoy falta una versión dedicada para hombre.

**Riesgo de canibalización**
- bajo si se trabaja como pieza específica masculina y se enlaza desde `tipos-de-rostros-de-hombre`.

---

### 2. Rostro redondo hombre: cómo identificarlo y qué cortes elegir

**Slug sugerido**
- `rostro-redondo-hombre`

**Keyword principal**
- `rostro redondo hombre`

**Longtails**
- `cara redonda hombre`
- `cortes para rostro redondo hombre`
- `peinados para cara redonda hombre`
- `barba para rostro redondo hombre`

**Por qué conviene**
- El sitio ya funciona bien con la lógica “forma de rostro + recomendaciones”.
- Hoy existe `rostro-redondo-mujer`, pero no una pieza equivalente para hombre.
- Es una expansión natural del cluster más prometedor que ya tenés.

**Riesgo de canibalización**
- bajo, siempre que el foco sea masculino y no se solape con `tipos-de-rostros-de-hombre`.

---

### 3. Smart casual hombre: cómo vestir casual formal sin errarle

**Slug sugerido**
- `smart-casual-hombre`

**Keyword principal**
- `smart casual hombre`

**Longtails**
- `casual formal hombre`
- `outfit casual formal hombre`
- `look smart casual hombre`
- `como vestir smart casual hombre`

**Por qué conviene**
- Search Console ya mostró una señal muy fuerte:
  - `outfit casual formal hombre`
  - `outfit hombre casual formal`
- Hoy esa intención está diluida dentro de `outfit-hombre`, pero merece una URL propia porque la búsqueda es mucho más concreta.

**Riesgo de canibalización**
- medio si no se reubica bien el enfoque.
- La solución es dejar `outfit-hombre` como pieza amplia y usar este post para intención específica `smart casual / casual formal`.

---

### 4. Outfit para oficina hombre: ideas casuales y prolijas para trabajar

**Slug sugerido**
- `outfit-oficina-hombre`

**Keyword principal**
- `outfit oficina hombre`

**Longtails**
- `look de oficina hombre`
- `outfit trabajo hombre`
- `como vestir para la oficina hombre`
- `outfit casual hombre oficina`

**Por qué conviene**
- `outfit-hombre` ya toca trabajo, pero solo como una subsección.
- La intención “ropa para oficina / trabajo” suele tener mejor foco comercial y práctico que un artículo genérico de outfits.
- Encaja perfecto con el tono del sitio: guías aplicables, fáciles de adaptar al guardarropa.

**Riesgo de canibalización**
- medio-bajo si se posiciona como artículo específico para trabajo/oficina.

---

### 5. Outfit para casamiento de día hombre: qué ponerse sin quedar rígido

**Slug sugerido**
- `outfit-casamiento-dia-hombre`

**Keyword principal**
- `outfit para casamiento de día hombre`

**Longtails**
- `como vestir para un casamiento de día hombre`
- `look para boda de día hombre`
- `ropa para matrimonio de día hombre`
- `outfit elegante hombre boda de día`

**Por qué conviene**
- Search Console ya mostró muy buena señal en:
  - `outfit para casamiento de día hombre`
- Hoy esa intención vive mezclada dentro de `como-vestir-para-una-boda`, una pieza más amplia y menos precisa.
- Este tema tiene una intención clarísima, buen potencial de CTR y además se presta muy bien a imágenes.

**Riesgo de canibalización**
- medio.
- Se resuelve dejando este artículo centrado en bodas de día para hombre y manteniendo `como-vestir-para-una-boda` como pieza general.

## Prioridad recomendada

1. `smart-casual-hombre`
2. `outfit-casamiento-dia-hombre`
3. `rostro-ovalado-hombre`
4. `rostro-redondo-hombre`
5. `outfit-oficina-hombre`

## Recomendación editorial

Para los dos primeros:
- usar imágenes generadas con varios looks en la misma escena
- apostar a bloques comparativos
- responder rápido la intención en el primer scroll

Para los de rostro:
- mantener consistencia con `cara-diamante-hombre`
- incluir:
  - cómo identificar la forma
  - cortes recomendados
  - peinados
  - barba o gafas si aplica

## Qué evitar

- abrir temas demasiado parecidos a `outfit-hombre` sin un ángulo claro
- crear otra pieza genérica de “looks para hombre”
- mezclar mujer y hombre en una misma URL cuando la query ya es claramente masculina
