# Auditoría SEO CTR - 2026-03-18

Propiedad analizada:
- `sc-domain:tuasesordemoda.com`

Ventana:
- `2025-12-18` a `2026-03-18`

Fuente:
- Search Console API

## Criterio de priorización

Se priorizaron combinaciones `URL + query` con:
- muchas impresiones
- posición promedio fuerte (`<= 5`)
- CTR bajo (`< 2%`)

Esto suele indicar páginas que ya rankean bien, pero no están capturando clics al nivel esperable.

## Top oportunidades

### 1. `cara-diamante-hombre`

URL:
- `/cara-diamante-hombre`

Motivo:
- acumula `7057` impresiones en queries con posición muy competitiva
- CTR medio del grupo: `0.46%`

Queries principales:
- `cortes rostro diamante hombre`
- `rostro diamante hombre`
- `cara diamante hombre`
- `cortes para rostro diamante hombre`
- `cortes para cara diamante hombre`

Acciones sugeridas:
- rehacer `title` para incluir de forma más directa:
  - `rostro diamante hombre`

  - `peinados`
- mejorar meta description con promesa más clara:
  - cortes recomendados
  - errores a evitar
  - ejemplos / famosos / peinados
- agregar un bloque inicial tipo:
  - `Si tienes rostro diamante, estos cortes favorecen...`
- sumar `FAQ` breve con queries derivadas
