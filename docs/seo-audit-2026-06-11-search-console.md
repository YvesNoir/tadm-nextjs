## Patrón general detectado

### 1. La recuperación es dominio-wide, no puntual

Observado:
- varias URLs grandes duplican o triplican impresiones
- también mejora la posición media general

Interpretación:
- no parece un simple rebote de una sola query
- hay una recuperación estructural de visibilidad

### 2. El cluster de rostros vuelve a liderar

Observado:
- `cara-diamante-hombre`
- `cara-cuadrada`
- `rostro-ovalado`

Interpretación:
- sigue siendo el cluster con más capacidad de empujar crecimiento

### 3. El cluster uñas está funcionando mejor

Observado:
- `color-de-unas-para-vestido-verde`
- `unas-para-vestido-negro`

Interpretación:
- son URLs que hoy combinan buena posición y crecimiento de impresiones

### 4. El cluster hombre todavía está partido

Observado:
- `cara-diamante-hombre` y `looks-con-bermudas-hombre` recuperan bien
- `outfit-hombre` mejora algo, pero sigue en posición muy floja

Interpretación:
- no todo el frente hombre se recuperó igual
- `outfit-hombre` sigue necesitando trabajo específico
